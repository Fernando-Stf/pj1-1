## 🔧 Como Usar

### Desenvolvimento Local
```bash
cd pj2
python -m http.server 8000
# Acesse: http://localhost:8000
```

### Customização Rápida

**Cores:** Edite `:root` em `styles.css`
```css
--accent: #c9a961;  /* Trocar para outra cor */
```

**Contato:**
```html
<!-- Procure por estes placeholders -->
https://wa.me/5511999999999
tel:+5511999999999
Rua Exemplo, 123
```

**Imagens:**
Substitua URLs do Unsplash por imagens locais:
```html
<img src="/images/hero.jpg" alt="...">
```

### Deploy

**Vercel (recomendado):**
```bash
npm install -g vercel
vercel
```

**Netlify:**
```bash
netlify deploy
```
